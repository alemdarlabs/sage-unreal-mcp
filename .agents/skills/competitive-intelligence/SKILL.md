# Competitive Intelligence

## Overview

Delivers structured comparative analysis (feature, capability, positioning) for product or technical research.

**Keywords**: competitive, analysis, comparison, swot, market, parity, audit, positioning

## Features

- Feature-by-feature matrix
- Strengths / Weaknesses / Opportunities / Threats
- Differentiation summary
- Risk callouts (areas where competitor is ahead)

## Output Format

- Comparison table (rows = features, columns = competitors + Sage)
- Per-competitor: 2-3 strengths, 2-3 weaknesses
- Sage-specific differentiation paragraph
- Top 3 risks/opportunities

## Instructions

- Identify the comparison set explicitly (don't include "all engine MCPs" — name them)
- Compare on observable, verifiable axes (transport, storage, indexing, distribution model, license)
- Distinguish "verified" vs "claimed" capabilities — many MCP tools have inflated marketing
- Highlight gaps Sage can exploit
- Cite sources for non-trivial claims

## Constraints

- Avoid bias toward Sage — honest assessment makes recommendations actionable
- Mark unverified claims explicitly ("source: their README, not tested")
- Token discipline: matrix-first, prose only for differentiation summary
